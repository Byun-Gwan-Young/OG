MCP 안내 페이지

officegenie-mcp.duckdns.org

MCP는 AI 앱이 외부 도구를 쓸 수 있게 해 주는 표준입니다. 저희는 오피스지니의 기능을 처음부터 MCP 도구로 만들었고, 웹 화면도 이 도구를 씁니다. 그래서 같은 도구를 인터넷에 열어 두기만 하면, 회사 웹에 들어오지 않아도 Claude Code 같은 AI 앱에서 바로 물어볼 수 있습니다. 실행 순서는 이렇습니다. 1. 사원이 웹 홈의 AI 앱 연결 카드에서 개인 토큰을 발급합니다. 2. 화면의 명령어 한 줄로 AI 앱에 MCP 서버 주소와 토큰을 등록합니다. 3. AI 앱에서 “내 남은 연차 알려줘”라고 물으면, AI 앱이 오피스지니 도구를 호출하고, MCP 서버는 요청마다 토큰을 DB에서 확인해서 그 토큰 주인의 회사와 사번으로 실행합니다. 토큰이 곧 신원이라 남의 연차는 웹과 똑같이 막힙니다. 토큰은 해시로만 저장하고, 폐기하면 다음 요청부터 바로 거부됩니다. 이 기능은 지금 실제 서버에 배포되어 동작하고 있습니다. 시간 관계상 시연은 웹으로만 보여 드리고, 오른쪽 QR로 연결 방법 안내 페이지를 보실 수 있습니다.
