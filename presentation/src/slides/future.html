향후 계획

다음 목표는 실제 회사와 학교에서 쓰는 것입니다

01

규정 파일 자동 변환

JSON · HWP · Word 등 어떤 파일을 올려도 자동으로 바꿔서 DB에 저장

02

실제 현장 파일럿

회사 · 학교 한 곳에 데이터를 올리고 피드백 받기

03

계정 연동

사내 SSO 로그인, AI 앱은 토큰 대신 OAuth 로그인

04

신청 알림

신청 처리 상태를 메일 · 메신저로 바로 알림

앞으로의 계획은 네 가지입니다. 첫째, 규정 파일 자동 변환입니다. 지금은 관리자가 정해진 JSON 양식에 맞춰 데이터를 올려야 합니다. 하지만 실제 회사나 학교는 규정을 한글 파일, 워드, PDF로 갖고 있습니다. 그래서 JSON이든 HWP든 Word든 어떤 파일을 올려도, 저희 쪽에서 우리 형식으로 바꿔서 DB에 알아서 넣어 주도록 만들 계획입니다. 이게 되면 도입하는 쪽은 갖고 있는 규정 파일을 그대로 올리기만 하면 됩니다. 둘째, 실제 회사나 학교 한 곳에 진짜 규정 데이터를 올려서 사용자 피드백을 받아 보려고 합니다. 셋째, 사내 계정으로 바로 로그인하는 SSO 연동과, AI 앱 연결을 토큰 복사 대신 OAuth 로그인으로 바꾸는 것입니다. 넷째, 비품 신청이 처리되면 메일이나 메신저로 알려 주는 기능입니다.
