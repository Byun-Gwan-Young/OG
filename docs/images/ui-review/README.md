## 고친 문제

1. 헤더 위 16px 빈 줄: 두 번째 `<style>` 블록이 요소 자리를 차지했다 → `st.html`로 넣어 자리를 없앰
2. 헤더의 사용자 이름이 로그아웃 버튼보다 7px 위에 있음 → 줄 높이를 맞춤
3. 모바일 하단 탭의 아이콘이 글자 옆에 있음, 관리자 탭 6개에서 "자료실"이 "자…"로 잘림 → 아이콘 위·글자 아래로 쌓음
4. 태블릿(768~1179px)에서 관리자 메뉴 6개가 헤더를 넘어 로그아웃이 화면 밖으로 나감 → 관리자는 1180px 미만에서 하단 탭바 사용
5. 관리자 헤더에 "관리자"가 두 번 보임 → 사용자 자리에 회사명 표시
6. 작은 안내 글(설명·건수·메모)이 본문 크기(16px)로 보임 → 13px로 맞춤
7. 비품 확인 카드의 안내문이 접수 확정 버튼과 겹침(Streamlit이 마지막 문단에 주는 음수 여백) → 여백을 고정
8. 모바일 챗봇 시트에서 입력창이 화면 가운데에 있고 아래가 비어 있음, 안내 문구가 아래에서 잘림 → 대화 영역이 남은 높이를 채우고 입력창은 맨 아래
9. 모바일에서 고정 탭바가 화면 아래쪽 입력칸·버튼을 가림 → `scroll-padding-bottom`으로 포커스 이동 시 여유 확보
10. 640px 미만에서 관리자 표가 칸마다 한 줄로 쪼개짐 → 행은 한 줄로 두고 가로 스크롤
11. 모바일 자료 행의 내려받기 버튼이 아이콘 아래로 떨어짐 → 글자 줄에 맞춤
12. 직원 화면 미리보기를 열어도 스크롤이 아래에 남아 미리보기 띠가 안 보임 → 열 때 맨 위로 이동
13. 관리자 홈 최근 공지에서 비공개 공지에 NEW만 붙음 → "비공개" 표시
14. 빈 신청 내역 안내가 "왼쪽에서"라고 함(모바일은 위쪽) → 위치와 무관한 문구로
15. 신청 내역 메타 정보가 어색하게 줄바꿈됨 → 번호·신청일 / 최근 변경을 두 줄로 나눔
16. 펼친 공지 본문이 목록보다 크게 보임 → 15px

## 그대로 둔 것

- 떠 있는 챗봇 버튼이 목록 오른쪽 아래 일부를 덮는다. 본문 아래 여백으로 스크롤하면 가려진 부분을 볼 수 있다.
- 모바일 관리자 표는 가로로 스크롤해야 모든 칸이 보인다(관리 업무는 PC 사용을 권장).
